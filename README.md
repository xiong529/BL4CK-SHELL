# KSH//NT — Secure Console

一个跑在 Windows 上的「黑客风」终端 + 代码编辑器，纯 Python + PyQt6 构建。

开机自检动画、真实硬件数据、3D 世界地图、命令补全、20+ 主题、事件音效——
外观与交互致敬 eDEX-UI，让你在朋友面前 cos 黑客，拥有更多炫酷命令与实用功能。

## 快速开始

1. **装 Python 3.9+**（[python.org](https://www.python.org/downloads/) 下载安装，勾选 *Add to PATH*）
2. **打开终端**（Win+R 输入 `cmd`，回车），进入本项目目录：

```powershell
cd D:\python\project\Terminal
```

3. **安装依赖**（首次运行需要）：

```powershell
pip install -r requirements.txt
```

4. **启动**：

```powershell
python main.py
```

看到 BIOS 自检动画和 3D 世界地图，就说明启动成功了。

## 3 分钟装逼演示

给朋友看这几个效果，比任何截图都有说服力：

| 演示 | 操作 |
|---|---|
| **流式输出不卡死** | 在终端里跑一个持续输出的脚本（见下方示例），输出一行行滚出来，界面不冻结 |
| **命令补全** | 输入 `os.` 按 Tab —— 竖排紧凑列表弹出，`· path` 排第一 |
| **3D 世界地图** | 右侧地球缓慢旋转，城市光晕 + 数据弧线动画 |
| **主题切换** | 20+ 主题一键切换，全局重新着色 |
| **开机自检** | 重启程序，看 BIOS 式硬件自检流（CPU/内存/磁盘/网络 IP 全真实数据） |

**流式输出示例** —— 新建 `demo.py` 粘贴下面代码，然后在终端里运行 `python demo.py`：

```python
import time
while True:
    print("\033[38;5;%dm" % (time.time() * 8 % 256) + "▉" * 40 + "\033[0m")
    time.sleep(0.1)
```

这是一段无限循环的彩虹滚动条，最能展示「长进程不被卡死、输出实时流式」的能力。

## 功能一览

**终端（term.py）**
- pyte 终端模拟，命令补全（紧凑竖排弹窗，对齐终端风格）
- 流式输出：长进程 / 无限循环不卡死，串行队列防崩溃
- 命令历史：`↑` / `↓` 翻找，回车执行
- `Ctrl+C` 终止进程 —— 会杀掉整棵进程树，不留孤儿进程
- 多行粘贴自动拆分为多条命令依次执行

**代码编辑器（editor.py）**
- 6 语言语法高亮：Python / JSON / HTML / Markdown / CSS / JS
- Python 补全弹窗：内置函数、模块、`obj.` 属性联想（如 `os.p` → `· path`）
- 括号 / 引号自动配对，当前行高亮，查找

**信息面板**
- CPU / 内存 / 磁盘 / 网络流量实时图表
- 进程列表、端口占用、文件树（与终端目录双向联动）

**世界地图（worldmap.py）**
- 预计算 3D 地球动画，城市光晕与数据弧线，性能优化后不拖慢界面

**主题与音效**
- 20+ 主题一键切换，全局重着色
- 13 个事件音效（开机 / 报错 / 键盘等，音频设备不可用时自动静音）

## 常见问题

**没有声音？**
程序依赖系统音频设备；无声卡或驱动异常时自动静音，不影响使用。

**启动动画时间有点长？**
自检动画要等真实硬件探测完成（约 1 秒），属正常现象，点鼠标/按键可跳过。

**终端跑的命令一直停不下来？**
按 `Ctrl+C`，会终止当前命令并杀掉它的所有子进程。

**程序关不掉 / 退出报错？**
当前版本已修复正常退出的崩溃问题（关窗即干净收尾，等待命令进程退出最多 8.5 秒）。

## 项目结构

| 文件 | 说明 |
|---|---|
| `main.py` | 主窗口装配：标题栏 / 三栏布局 / 标签页 / boot 覆盖层 |
| `term.py` | 终端：pyte 模拟、串行 feed 队列、ANSI 极速解析、命令补全 |
| `editor.py` | 编辑器：规则表高亮引擎、补全、自动配对 |
| `panels.py` / `sidebar.py` / `monitor.py` | 左侧信息栏 / 右侧栏 / 监控页 |
| `worldmap.py` | 预计算 3D 世界地图动画 |
| `theme.py` / `audio.py` | 主题系统 / 音效 |
| `boot.py` | 开机自检动画 |
| `langdata/python.json` | Python 词表（JSON 数据驱动） |
| `assets/` | 音效与主题 JSON |
| `_regress.py` | 回归测试（20 用例） |
